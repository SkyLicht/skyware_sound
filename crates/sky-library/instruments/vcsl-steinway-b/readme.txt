Steinway Model B grand piano from the Versilian Community Sample Library
(VCSL) by Versilian Studios: https://github.com/sgossner/VCSL

License: CC0 1.0 Universal. "Essentially it's Public Domain- you can do
whatever you want with these sounds (even make commercial software), no
royalties, no credit, no special terms." (VCSL README)

The SFZ file here is VCSL's own (SFZ build v1.2.2, generated by Peter
Eastman's createInstruments.py, also CC0), from the tag v1.2.2-RC at
commit b6e6ac82d22248edee98a0bde185eb9ef6d439ad, keeping the regions
recorded without the sustain pedal and the release samples. Skyware Sound
downloads those 225 recordings from that commit, each checked against the
SHA-256 it lists, and plays them with its own sustain pedal.
