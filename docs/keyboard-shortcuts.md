# Keyboard shortcuts

<!-- Made from crates/sky-ui/src/keys.rs; a test fails when the two differ. -->

Ctrl is Cmd on a Mac. Keys marked Arrangement or Piano roll work in whichever of the two you clicked last.

## File

| Keys | Does | Where |
| --- | --- | --- |
| Ctrl+O | Open a project | Anywhere |
| Ctrl+S | Save | Anywhere |
| Ctrl+Shift+S | Save as a new project | Anywhere |
| Ctrl+Q | Quit | Anywhere |

## Edit

| Keys | Does | Where |
| --- | --- | --- |
| Ctrl+Z | Undo | Anywhere |
| Ctrl+Shift+Z or Ctrl+Y | Redo | Anywhere |
| Ctrl+X | Cut | Anywhere |
| Ctrl+C | Copy | Anywhere |
| Ctrl+V | Paste at the playhead | Anywhere |
| Ctrl+D | Duplicate right after | Anywhere |
| Del or Backspace | Delete | Anywhere |
| Ctrl+A | Select all | Anywhere |
| Esc | Select nothing | Anywhere |

## Selection

| Keys | Does | Where |
| --- | --- | --- |
| Left | Nudge left by the grid | Anywhere |
| Right | Nudge right by the grid | Anywhere |
| Shift+Left | Nudge left by a bar | Anywhere |
| Shift+Right | Nudge right by a bar | Anywhere |
| Up | Move clips to the track above | Arrangement |
| Down | Move clips to the track below | Arrangement |
| Up | Notes up a semitone | Piano roll |
| Down | Notes down a semitone | Piano roll |
| Shift+Up | Notes up an octave | Piano roll |
| Shift+Down | Notes down an octave | Piano roll |

## Transport

| Keys | Does | Where |
| --- | --- | --- |
| Space | Play or pause | Anywhere |
| Ctrl+L | Loop on or off | Anywhere |

## View

| Keys | Does | Where |
| --- | --- | --- |
| Ctrl+B | Show or hide the browser | Anywhere |
| Plus or = | Zoom the timeline in | Anywhere |
| Minus | Zoom the timeline out | Anywhere |
| F | Fit the timeline to the song or clip | Anywhere |
| Ctrl+Plus or Ctrl+= | Make everything bigger | Anywhere |
| Ctrl+Minus | Make everything smaller | Anywhere |
| Ctrl+0 | Actual size | Anywhere |

## Help

| Keys | Does | Where |
| --- | --- | --- |
